# 鲁迅原句查出处 · Agent Skill

检索自己电脑上的《鲁迅全集》OCR PDF，查找原句的篇名、卷页和初刊注释，并提供扫描页定位，便于人工核验。

**[下载 Skill 安装包](https://github.com/sunoharayuzuki-debug/luxun-quote-finder/raw/refs/heads/main/downloads/luxun-text-search.zip)**

本仓库发布 Skill 分享版，只提供程序和说明，**不含《鲁迅全集》PDF、OCR 全文、注释数据库或私人配置**。使用者自行准备有权使用的语料。这里不是在线全文查询网站。

## 安装到 Codex

1. 下载并解压上面的 ZIP，得到 `luxun-text-search` 文件夹。
2. 将整个文件夹放入用户目录下的 `.codex/skills/`。macOS 的默认位置是 `~/.codex/skills/`；如果设置了 `CODEX_HOME`，使用其 `skills/` 目录。
3. 重新打开会话，说：

   > 使用 $luxun-text-search，帮我导入本地的鲁迅全集 OCR PDF。

4. 提供自己电脑上的 PDF 文件夹路径，按提示准备 Python 环境并建立索引。
5. 之后可以直接问：

   > 使用 $luxun-text-search，查“其实地上本没有路”的篇名、卷页和初刊注释。

需要 Python 3.10 或更高版本；导入 PDF 另需 `pypdf`，查询已有索引只使用 Python 标准库。安装与命令行说明见 [setup.md](skills/luxun-text-search/references/setup.md)。其他支持 Agent Skills 的客户端需要提供本地脚本执行能力；上传 ZIP 到普通聊天并不保证能运行。

## 能做什么

- 精确查询忽略标点、空白与全半角差异，支持相邻页边界匹配。
- 可限定卷次，无精确结果时尝试部分错字的近似匹配。
- 返回短上下文、篇名候选、印刷页码、PDF 页序及相关发表注释候选。
- 保留原文件路径，方便回到扫描页核验。

## 学术与数据边界

篇目、页码和发表信息通过 OCR 自动识别，不是经过逐篇校勘的权威数据库。命中可能位于编者注释或索引，不能直接认定为鲁迅原话；未命中也不能证明鲁迅未写过。文章初刊信息不保证当前句式原样见于初刊。

目标版本为用户指定的人民文学出版社 2005 年版，程序不会鉴定输入文件的版本。正式引用前请核查扫描页与版本信息。

脚本本身不发起联网请求；但命令输出可能进入客户端的云端模型。因此默认只返回少量片段，不承诺使用云端 AI 时语料完全不出本机。
